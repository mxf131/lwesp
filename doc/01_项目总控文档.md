# LwESP 项目总控文档

> 创建日期：2026-05-03 | 版本：v1.1.2-dev | 许可证：MIT

## 一、项目概览

| 维度 | 说明 |
|------|------|
| **项目名称** | LwESP — Lightweight ESP-AT parser library |
| **项目类型** | 嵌入式 C 库（非应用项目） |
| **核心功能** | 通过 AT 指令与 ESP8266/ESP32 系列 Wi-Fi 模块通信 |
| **原作者** | Tilen MAJERLE \<tilen@majerle.eu\> |
| **仓库地址** | https://github.com/MaJerle/lwesp |
| **文档站点** | https://docs.majerle.eu/projects/lwesp/ |
| **语言标准** | C99 |
| **构建系统** | CMake ≥ 3.22 + Ninja |
| **代码格式化** | clang-format（项目根 `.clang-format`） |

## 二、技术栈详情

### 核心依赖
